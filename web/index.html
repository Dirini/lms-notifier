3텔레그램 알림

확인 중

텔레그램 봇 처음 만드는 법 · 2분이면 돼요

  1. BotFather 열기 — t.me/BotFather 를 누르면 텔레그램에서 대화창이 열려요. (파란 체크가 붙은 공식 계정이 맞는지 확인)
  2. 봇 만들기 — 대화창에 /newbot 을 보내요.
  3. 봇 이름 — 아무 이름이나 정해요. (예: 내 LMS 알리미)
  4. 봇 아이디 — 반드시 _bot 으로 끝나야 해요. (예: hgu_lms_min_bot) 이미 쓰는 이름이면 거절돼요. 그럼 앞에 아무 글자나 붙여 다시 시도하세요.
  5. 토큰 복사 — BotFather 가 1234567:AAExx... 모양의 토큰을 줘요. 그걸 복사해 아래 봇 토큰 칸에 붙여넣어요. 이 토큰은 비밀번호와 같아요. 남에게 주지 말고 각자 만드세요.
  6. 내 봇 열기 — BotFather 가 준 t.me/…_bot 링크를 누르면 내 봇 대화창이 열려요. 거기서 시작(Start) 버튼을 누르거나 아무 메시지나 한 번 보내요. 이걸 해야 봇이 "누구에게 보낼지"를 알 수 있어요. 안 하면 다음 단계가 비어 나와요.
  7. chat_id 확인 — 방금 메시지를 보낸 직후, 아래 chat_id 확인 버튼을 누르면 자동으로 채워져요.
  8. 연결하기 — 확인 메시지가 봇에게 오면 끝이에요.

잘 안 되면: ① 봇에게 메시지를 먼저 보냈는지 ② 토큰을 공백 없이 붙여넣었는지 확인하세요.

먼저 1번 LMS 계정을 연결하세요.
