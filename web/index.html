1LMS 계정

확인 중
🔑
학교 LMS가 Canvas라면 어디든 돼요. LMS에서 발급한 액세스 토큰으로 연결하니 비밀번호를 저장하지 않아요.
토큰은 어디서 발급하나요?
  1. 브라우저로 학교 LMS에 로그인해요.
  2. 왼쪽 계정(Account) → 설정(Settings)으로 들어가요.
  3. 아래 승인된 통합(Approved Integrations)에서 + 새 액세스 토큰을 눌러요.
  4. 용도에 아무 이름이나 적고 만든 뒤, 딱 한 번만 보이는 토큰을 복사해 위에 붙여넣어요.

이 항목이 없다면 학교가 토큰 발급을 막아둔 거예요. 그때는 이 방식으로 연결할 수 없어요.

🔒
자동 로그인을 위해 비밀번호가 이 컴퓨터의 파일에 암호화 없이 저장돼요. 본인만 읽을 수 있게 권한이 걸리지만, 공용 PC에서는 쓰지 마세요. "연결 해제"를 누르면 파일에서 지워져요.
