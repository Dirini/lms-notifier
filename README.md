# LMS 알리미 (한동대 LMS 과제·공지 텔레그램 알리미)

한동대 LMS(Canvas)에 학번/비밀번호로 로그인해서 앞으로 며칠 안의 **과제/퀴즈/일정**과 **공지사항**을 가져와,
새로 생긴 것만 텔레그램으로 알려주는 도구입니다. 웹 화면(카드 UI)에서 계정을 연결하고 실행 버튼을 누르는 방식입니다.

> **AI에게 시키려면**: Claude Code·Cursor 같은 AI에게 이 저장소 링크를 주고 "설치해줘"라고 하면,
> `AGENTS.md`를 읽고 터미널 명령까지 대신 실행합니다. (학번·비밀번호·봇 토큰만은 본인이 직접 입력)

## 1. 설치

**필요한 것: Python 3.9 이상.** Git은 필요 없습니다.

### 방법 A — 터미널 한 줄 (맥, 가장 확실함 · 추천)

더블클릭은 맥 보안(Gatekeeper) 때문에 "확인되지 않은 개발자"로 막히는 경우가 많습니다.
아래 방법은 그 문제를 아예 우회합니다.

1. **터미널**을 엽니다. (`⌘+스페이스` → `터미널` 입력 → 엔터)
2. 아래 한 줄을 **붙여넣고 엔터**:

```bash
curl -fsSL https://raw.githubusercontent.com/Dirini/lms-notifier/main/install.command | bash
```

3. 자동으로 내려받고 설치·실행되며 브라우저가 열립니다.
   (Python이 없으면 받는 페이지를 열어줘요. 설치 후 같은 줄을 다시 붙여넣으세요.)

> 이 한 줄이 하는 일: 최신 코드를 홈 폴더의 `lms-notifier` 로 내려받아 `bootstrap.py` 를 실행.
> 맥 기본 도구(curl)만 쓰므로 **Git 도, 파일 다운로드도 따로 필요 없습니다.**

### 방법 A-2 — ZIP + 더블클릭 (맥/윈도우)

1. ZIP 내려받아 압축 풀기: <https://github.com/Dirini/lms-notifier/archive/refs/heads/main.zip>
2. 폴더 안 파일을 더블클릭 — **맥은 `install.command`, 윈도우는 `install.bat`**
   - 맥에서 **안 열리거나 "확인되지 않은 개발자"가 뜨면**: 파일을 **우클릭 → 열기 → (다시) 열기**.
     그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안**에서 아래로 내려 **"확인 없이 열기"** 를 누르세요.
     (이게 번거로우면 위 **방법 A(터미널 한 줄)** 가 제일 확실합니다.)
   - 윈도우에서 "Windows의 PC 보호"가 뜨면 **추가 정보 → 실행**.
3. Python이 없으면 받는 곳을 자동으로 열어줍니다. 설치 후 다시 더블클릭하세요.

### 방법 B — 터미널에 익숙하다면 (Git 사용)

```bash
git clone https://github.com/Dirini/lms-notifier.git
cd lms-notifier
python3 bootstrap.py      # 윈도우는 py bootstrap.py
```

`bootstrap.py`가 가상환경 생성 + 패키지 설치 + 웹 서버 실행까지 한 번에 처리합니다.
(윈도우 가상환경 경로도 자동으로 처리합니다.)

### Python이 없다면 (공통)

Python이 안 깔려 있으면 아래에서 받아 설치하세요(5분). 설치 파일도 방법 A가 자동으로 열어줍니다.
- **맥**: <https://www.python.org/downloads/macos/>
- **윈도우**: <https://www.python.org/downloads/windows/>
  → 설치 첫 화면에서 **"Add Python to PATH"** 체크를 꼭 켜세요. 안 켜면 인식이 안 됩니다.

## 2. 텔레그램 봇 만들기 (각자 하나씩)

1. 텔레그램에서 `@BotFather` 검색 후 대화 시작
2. `/newbot` 입력 → 이름/아이디 설정 → 발급된 토큰 복사

> ⚠️ **봇 토큰은 남에게 주지 마세요. 각자 자기 봇을 만드세요.**
> 토큰은 그 봇을 완전히 조종할 수 있는 열쇠입니다. 토큰을 가진 사람은 그 봇에게 말을 건
> **다른 사람들의 chat_id와 텔레그램 이름을 조회**할 수 있고, 봇 이름으로 아무 메시지나
> 보낼 수 있습니다. 또 여러 명이 한 봇을 쓰면 설정 중에 **남의 chat_id가 내 것으로 잡혀
> 내 과제 알림이 엉뚱한 사람에게 가는** 사고가 실제로 일어납니다.

## 3. 실행 (웹 화면)

1번에서 `python3 bootstrap.py`를 실행했다면 이미 서버가 켜져서 브라우저가 열려 있을 거예요.
다음번부터 다시 켤 때는 이렇게 하면 됩니다:

```bash
python3 bootstrap.py
```

(수동으로 하고 싶다면: `source .venv/bin/activate` 후 `python src/server.py`. Windows는
`.venv\Scripts\activate`.)

브라우저가 자동으로 열립니다(안 열리면 `http://127.0.0.1:8912` 접속). 화면은 순서대로 진행하는 4단계 카드입니다 — 앞 단계가 끝나야 다음 카드가 열리고, 끝난 카드는 번호가 초록색으로 바뀌며 "완료"로 표시됩니다.

1. **LMS 계정**: 위 표의 두 방식 중 하나를 고르고 값을 입력 → 연결하기 (실제로 접속되는지 그 자리에서 바로 확인합니다)
2. **가져올 항목** (선택): 기본은 전체 과목 · 전체 유형(과제/퀴즈/일정/토론/메모/공지사항)이에요. "과목 불러오기"로 내 수강 과목 목록을 가져와서 필요 없는 과목이나 유형은 꺼둘 수 있어요. 건드릴 때마다 바로 저장됩니다(따로 저장 버튼 없음).
3. **텔레그램 알림**: 봇 토큰 입력 → "봇에게 메시지 보낸 뒤 chat_id 확인" 버튼으로 자기 `chat_id` 자동 조회 → 연결하기
4. **지금 확인**: "지금 확인해서 보내기" 버튼으로 즉시 실행, 실행 이력이 아래에 쌓입니다. "자동 확인"에서 반복 주기나 정해진 시각을 정할 수 있고, **알림 내용**을 "간단히 / 자세히" 중에 고를 수 있어요.
   - **자세히** — 분류·과목·마감 시각·제출 여부까지 전부 담습니다.
   - **간단히** — 날짜와 제목만 한 줄씩, 이미 제출한 과제는 빼고 보냅니다.

   두 형식의 **실제 메시지 미리보기가 나란히** 떠서, 비교해 보고 카드를 눌러 고르면 됩니다.

### 확인을 놓쳤을 때

노트북이 꺼져 있거나 이 프로그램이 실행 중이 아니면 그 시각의 확인은 **실행되지 않고 건너뜁니다**(다음 실행을 항상 현재 시각 기준으로 다시 잡습니다). 다시 켜면 화면 위쪽에 `N번 확인하지 못했어요 · 마지막 확인은 …` 배너가 뜨고, 거기서 바로 확인을 돌릴 수 있어요.

놓친 동안 올라온 글이 사라지지는 않습니다 — 다음 확인 때 LMS를 다시 통째로 읽고 이미 보낸 것만 걸러내므로, 못 받았던 글은 그때 함께 옵니다. **누락이 아니라 지연입니다.**

연결 정보와 필터 설정은 다음 실행 때도 그대로 남아 있어서, 서버를 껐다 켜도 다시 입력할 필요 없습니다.

## 로그인이 느리거나 응답이 없을 때 (한동대 방식)

로그인은 학교 SSO → Canvas 순서로 실제 서버를 5단계 거칩니다. 버튼을 누르면 "n초째 확인 중이에요"가 뜨는데 이건 멈춘 게 아니라 실제로 학교 서버 응답을 기다리는 중입니다 (보통 몇 초, 느리면 수십 초). 각 단계는 15초를 넘기면 자동으로 실패 처리되고 **어느 단계에서 멈췄는지 화면에 그대로 뜹니다** (예: "'2/5 통합 로그인 제출' 단계에서 학교 서버 응답이 15초 넘게 없었습니다"). 터미널(서버를 실행한 창)에도 각 단계가 몇 초 걸렸는지 로그가 남으니, 계속 안 되면 그 로그와 화면 오류 문구를 그대로 알려주세요.

**이 5단계는 한동대 SSO 자체의 절차라 저희가 줄일 수는 없습니다** — 한동대가 학교 계정(히즈넷) → 통합 로그인 게이트웨이 → Canvas 3단계를 거치도록 만들어놨고, 브라우저로 직접 로그인해도 똑같이 이 경로를 탑니다. 대신 **첫 로그인 이후 25분 동안은 로그인 세션을 재사용**하도록 만들어서, 1단계 계정 연결 → 2단계 과목 불러오기 → 4단계 지금 확인처럼 짧은 시간 안에 여러 동작을 할 때는 맨 처음 한 번만 느리고 나머지는 로그인 단계를 건너뛰고 바로 응답합니다(자동 확인 스케줄러도 마찬가지). 세션이 만료된 걸로 보이면 자동으로 한 번 더 로그인해서 재시도합니다.

## 창을 안 띄우고 정해진 시각에 돌리기 (선택)

웹 화면에서 한 번 연결해 두면 같은 정보로 커맨드라인에서도 실행됩니다.

```bash
python src/main.py --dry-run   # 텔레그램 전송 없이 결과만 확인
python src/main.py             # 실제로 전송
```

이걸 스케줄러에 걸면 서버 창 없이도 돕니다. 컴퓨터가 꺼져 있으면 이것도 안 돕니다.

**macOS/Linux (cron):**

```bash
crontab -e
# 매일 오전 8시, 오후 6시에 확인
0 8,18 * * * cd /path/to/lms-notifier && .venv/bin/python src/main.py >> run.log 2>&1
```

**Windows (작업 스케줄러):** `.venv\Scripts\python.exe`로 `src\main.py`를 실행하는 작업을 등록하세요.

웹 화면 없이 쓰려면 `cp .env.example .env` 후 값을 채우면 됩니다(`.env`가 우선합니다).

## 보안 참고사항

- 히즈넷 비밀번호는 자동 로그인을 위해 `.local/secrets.json`에 **암호화 없이** 저장됩니다(파일 권한 0600, 본인만 읽기). 공용 PC에서는 쓰지 마세요.

- 이 폴더를 남에게 줄 때는 **코드만** 주세요(`git clone` 하거나 zip으로 줄 때 `.local/`, `.env`, `state.json`, `.venv/`는 절대 포함하지 마세요 — 이미 `.gitignore`에 있지만 zip으로 직접 압축할 땐 사람이 실수할 수 있으니 한 번 더 확인하세요).
- 서버는 로컬(`127.0.0.1`)에서만 열리고, 같은 와이파이의 다른 사람은 접속할 수 없습니다.
- 로컬 서버에는 로그인이 없기 때문에, 웹서핑 중 방문한 사이트가 몰래 이 서버를 조종하지
  못하도록 요청의 출처(`Host`/`Origin`)를 검사해 다른 곳에서 온 요청은 거부합니다.
- 로그인은 한동대 통합로그인(SSO) → 캔버스 순서로 진행됩니다. 학교가 로그인 페이지 구조를 바꾸면 동작하지 않을 수 있고, 그럴 경우 화면에 실패 메시지가 뜹니다 (조용히 실패하지 않습니다).
