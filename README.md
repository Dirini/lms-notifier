# LMS 알리미 (한동대 LMS 일정/공지 텔레그램 알리미)

한동대 캔버스 LMS(lms.handong.edu)에 로그인해서 앞으로 며칠 안의 **과제/퀴즈/일정**과 **공지사항**을 가져와,
새로 생긴 것만 텔레그램으로 알려주는 도구입니다. 웹 화면(카드 UI)에서 계정을 연결하고 실행 버튼을 누르는 방식입니다.

> **AI 에이전트에게 설치를 시키는 경우**: "이거 설치해줘"라고 링크만 주면 됩니다. 에이전트는
> `python3 bootstrap.py` 한 줄로 설치+실행까지 끝낼 수 있고, 세부 규칙은 [AGENTS.md](AGENTS.md)에
> 있습니다 (학번/비밀번호는 에이전트가 아니라 사람이 직접 입력해야 한다는 규칙 포함).

- **각자 자기 PC에서, 자기 계정으로 실행합니다.** 학번/비밀번호·봇 토큰은 이 폴더 안 `.local/secrets.json`(로컬 파일)에만 저장되고, 이 컴퓨터 밖 어디로도(개발자에게도, 다른 서버에도) 전송되지 않습니다. 서버는 `127.0.0.1`(내 컴퓨터 안)에서만 열립니다.
- 중복 알림 방지를 위해 이미 보낸 항목은 `state.json`에 기록해 두고 다음부터는 건너뜁니다.
- **누군가와 이 도구를 공유할 때는 이 폴더의 코드만 그대로 넘기세요.** `.local/`, `.env`, `state.json`은 각자 자기 계정 정보가 들어가는 파일이라 `.gitignore`에 이미 포함되어 있고, 절대 같이 넘기면 안 됩니다.

## 1. 설치

Python 3.9 이상만 있으면 됩니다.

```bash
git clone <이 저장소 URL>
cd lms-notifier
python3 bootstrap.py
```

`bootstrap.py`가 가상환경 생성 + 패키지 설치 + 웹 서버 실행까지 한 번에 처리하고, 끝나면
브라우저가 자동으로 열립니다. (수동으로 하고 싶다면 아래 3번 "실행" 참고.)

## 2. 텔레그램 봇 만들기 (한 번만, 대표 한 명이 하면 됨)

1. 텔레그램에서 `@BotFather` 검색 후 대화 시작
2. `/newbot` 입력 → 이름/아이디 설정 → 발급된 토큰 복사
3. 이 토큰을 알림 받을 사람 모두에게 공유하세요. 봇 하나를 여러 명이 같이 써도 됩니다 — 각자 자기 `chat_id`로 구분되어 알림도 각자에게만 갑니다.

## 3. 실행 (웹 화면)

1번에서 `python3 bootstrap.py`를 실행했다면 이미 서버가 켜져서 브라우저가 열려 있을 거예요.
다음번부터 다시 켤 때는 이렇게 하면 됩니다:

```bash
python3 bootstrap.py
```

(수동으로 하고 싶다면: `source .venv/bin/activate` 후 `python src/server.py`. Windows는
`.venv\Scripts\activate`.)

브라우저가 자동으로 열립니다(안 열리면 `http://127.0.0.1:8912` 접속). 화면은 순서대로 진행하는 4단계 카드입니다 — 앞 단계가 끝나야 다음 카드가 열리고, 끝난 카드는 번호가 초록색으로 바뀌며 "완료"로 표시됩니다.

1. **LMS 계정**: 학번/히스넷 비밀번호 입력 → 연결하기 (실제 로그인이 되는지 그 자리에서 바로 확인합니다)
2. **가져올 항목** (선택): 기본은 전체 과목 · 전체 유형(과제/퀴즈/일정/토론/메모/공지사항)이에요. "과목 불러오기"로 내 수강 과목 목록을 가져와서 필요 없는 과목이나 유형은 꺼둘 수 있어요. 건드릴 때마다 바로 저장됩니다(따로 저장 버튼 없음).
3. **텔레그램 알림**: 봇 토큰 입력 → "봇에게 메시지 보낸 뒤 chat_id 확인" 버튼으로 자기 `chat_id` 자동 조회 → 연결하기
4. **지금 확인**: "지금 확인해서 보내기" 버튼으로 즉시 실행, 실행 이력이 아래에 쌓입니다. 아래 "자동 확인 주기" 칩(끄기/15분/30분/1시간/3시간/6시간)으로 주기적으로 자동 확인하게 할 수도 있습니다 — 자세한 건 5번 참고.

연결 정보와 필터 설정은 다음 실행 때도 그대로 남아 있어서, 서버를 껐다 켜도 다시 입력할 필요 없습니다.

## 로그인이 느리거나 응답이 없을 때

로그인은 학교 SSO → Canvas 순서로 실제 서버를 5단계 거칩니다. 버튼을 누르면 "n초째 확인 중이에요"가 뜨는데 이건 멈춘 게 아니라 실제로 학교 서버 응답을 기다리는 중입니다 (보통 몇 초, 느리면 수십 초). 각 단계는 15초를 넘기면 자동으로 실패 처리되고 **어느 단계에서 멈췄는지 화면에 그대로 뜹니다** (예: "'2/5 통합 로그인 제출' 단계에서 학교 서버 응답이 15초 넘게 없었습니다"). 터미널(서버를 실행한 창)에도 각 단계가 몇 초 걸렸는지 로그가 남으니, 계속 안 되면 그 로그와 화면 오류 문구를 그대로 알려주세요.

**이 5단계는 한동대 SSO 자체의 절차라 저희가 줄일 수는 없습니다** — 한동대가 학교 계정(히스넷) → 통합 로그인 게이트웨이 → Canvas 3단계를 거치도록 만들어놨고, 브라우저로 직접 로그인해도 똑같이 이 경로를 탑니다. 대신 **첫 로그인 이후 25분 동안은 로그인 세션을 재사용**하도록 만들어서, 1단계 계정 연결 → 2단계 과목 불러오기 → 4단계 지금 확인처럼 짧은 시간 안에 여러 동작을 할 때는 맨 처음 한 번만 느리고 나머지는 로그인 단계를 건너뛰고 바로 응답합니다(자동 확인 스케줄러도 마찬가지). 세션이 만료된 걸로 보이면 자동으로 한 번 더 로그인해서 재시도합니다.

## 실제 테스트하는 법

이 도구는 실제 계정으로만 끝까지 확인할 수 있습니다(비밀번호는 로컬에만 저장되므로 저는 대신 로그인해볼 수 없어요). 직접 해보실 때:

1. `python src/server.py`로 서버를 켜고 본인 학번/히스넷 비밀번호로 1단계를 연결해 보세요. 실패하면 화면에 이유가 그대로 뜹니다.
2. 2단계에서 "과목 불러오기"를 눌러 실제 수강 과목 이름이 맞게 나오는지 확인하세요.
3. 4단계 "지금 확인해서 보내기"를 눌러 텔레그램으로 실제 온 알림이 기대한 것과 맞는지 확인하세요 (과제/공지 제목·마감일·과목명 등).
4. 이상한 점(과목명이 이상함, 날짜가 안 맞음, 로그인은 되는데 항목이 하나도 안 나옴 등)이 있으면 캡처나 문구를 그대로 알려주시면 고칠게요. **비밀번호만 아니면** 화면 내용을 그대로 공유해도 됩니다.

## 알림 주기 — 얼마나 자주, 얼마나 빨리 알려줄지

캔버스는 새 글이 올라오는 순간 우리에게 알려주는 기능(웹훅)이 없어서, **완전한 실시간(뜨는 즉시)은 기술적으로 불가능**합니다. 대신 이 도구는 "주기적으로 확인해서, 그때까지 못 봤던 것만 바로 보내는" 방식으로 최대한 가깝게 흉내 냅니다. 방법은 두 가지입니다.

**A. 웹 화면에 내장된 자동 확인 (기본, 추천)** — 4단계 카드에서 방식을 고를 수 있어요.

- **반복 주기**: 15분/30분/1시간/3시간/6시간 중 하나로, 그 간격마다 계속 확인해요. 최소 15분인 이유는 매번 학교 SSO에 새로 로그인하기 때문 — 너무 자주 돌리면 학교 서버에 부담이 되고 계정이 이상 트래픽으로 잠길 수도 있어서예요.
- **정해진 시각**: "매일 09:00, 18:30처럼 특정 시각에만 확인"하고 싶을 때. 시각을 원하는 만큼 추가할 수 있고, 그 시각들에만 확인해서 보내요.

둘 다 `python src/server.py`를 켜둔 동안에만 동작합니다. 컴퓨터를 끄거나 터미널을 닫으면 자동 확인도 멈춰요.

**B. 컴퓨터가 꺼져있어도 동작하게 하려면 (선택, 고급)** — 웹 화면에서 한 번 연결해 두면, 같은 정보를 커맨드라인(`src/main.py`)으로도 재사용할 수 있습니다. 이걸 macOS는 cron이나 launchd, Windows는 작업 스케줄러에 등록하면 서버 창을 안 띄워도 정해진 시각마다 실행됩니다. 컴퓨터 자체가 꺼져 있으면 이것도 당연히 안 돌아갑니다(진짜 24시간 알림이 필요하면 켜둔 컴퓨터나 서버가 있어야 해요 — 지금 이 도구는 각자 자기 PC에서 도는 구조라 그 이상은 범위 밖입니다).

```bash
python src/main.py --dry-run   # 텔레그램 전송 없이 결과만 확인
python src/main.py             # 실제로 텔레그램 전송
```

**macOS/Linux (cron):**

```bash
crontab -e
# 매일 오전 8시, 오후 6시에 확인
0 8,18 * * * cd /path/to/lms-notifier && .venv/bin/python src/main.py >> run.log 2>&1
```

**Windows (작업 스케줄러):** `.venv\Scripts\python.exe`로 `src\main.py`를 실행하는 작업을 원하는 시각에 등록하세요.

웹 화면 없이 `.env` 파일만으로 쓰고 싶다면 `cp .env.example .env` 후 값을 채우면 됩니다 (`.local/secrets.json`이 있으면 그쪽이 우선순위가 낮고 `.env` 값이 있으면 `.env`가 우선합니다).

## 보안 참고사항

- 이 폴더를 남에게 줄 때는 **코드만** 주세요(`git clone` 하거나 zip으로 줄 때 `.local/`, `.env`, `state.json`, `.venv/`는 절대 포함하지 마세요 — 이미 `.gitignore`에 있지만 zip으로 직접 압축할 땐 사람이 실수할 수 있으니 한 번 더 확인하세요).
- 서버는 로컬(`127.0.0.1`)에서만 열리고, 같은 와이파이의 다른 사람은 접속할 수 없습니다.
- 로그인은 한동대 통합로그인(SSO) → 캔버스 순서로 진행되며, 학교 쪽에서 로그인 페이지 구조를 바꾸면 동작하지 않을 수 있습니다. 그럴 경우 화면에 로그인 실패 메시지가 뜹니다 (조용히 실패하지 않습니다).
